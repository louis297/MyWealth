# Local docs

Private working notes. The starter files in this folder are tracked. Anything you do not want committed goes in `local_docs/private/` (gitignored).

Use this folder to think out loud. When a note becomes a decision, move the useful parts into [`docs/`](../docs/README.md).

## Suggested files

These are created as empty-ish templates. Rename, split, or delete them as you like — they will not be committed.

| File | Use for |
| --- | --- |
| [scratch.md](scratch.md) | Unsorted dump |
| [ideas.md](ideas.md) | Product ideas that are not in the function plan yet |
| [research-notes.md](research-notes.md) | Links, quotes, comparisons (banks, brokers, other apps) |
| [session-log.md](session-log.md) | What you did / next time, per sitting |
| `private/` | Gitignored. Real notes, dumps, credentials-adjacent scratch |

## Promotion checklist

Before copying into `docs/`:

- [ ] One topic per file (or per section in the official doc)
- [ ] A decision, not only a list of options
- [ ] Terms match [docs/glossary.md](../docs/glossary.md)
- [ ] `status` set to `draft` or `review`
